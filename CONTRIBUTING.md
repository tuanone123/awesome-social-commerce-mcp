# Contributing

Thanks for helping keep this list useful! Please follow these rules so the list stays high-quality.

## What belongs here

MCP servers (or agent toolkits that speak MCP) related to **social media, marketing, advertising, or e-commerce/commerce**. Think: storefronts, payments, ad platforms, social posting/analytics, CRM, email, CMS, and web data used for commerce.

## Entry format

Add your entry to the most relevant category, in this exact shape:

```markdown
- 🌍🏢 **[Name](https://link-to-repo-or-docs)** — One concise sentence on what it does.
```

Use the legend icons from the README:

- 🏢 Official · 👥 Community
- 🌍 Remote (hosted HTTP/SSE) · 💻 Local (stdio)

## Quality bar

- The link must work and point to a **real, public** project (GitHub repo or official docs).
- One sentence, no marketing fluff, no emojis inside the description.
- Keep the list alphabetical-ish within a category where possible; featured/official may lead.
- No dead projects, no paywalled-only demos, no affiliate links.

## How to submit

1. Fork the repo and create a branch.
2. Edit `README.md` (and ideally `README.vi.md` to keep both languages in sync).
3. Open a Pull Request with a title like `Add <Name> (<category>)` and a one-line reason.

PRs that add real, on-topic, working servers get merged quickly. Thank you!
